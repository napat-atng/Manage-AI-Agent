# Phase 18 — End-to-End

## Goal
พิสูจน์ V1 user journey บน local stack ตั้งแต่ login ถึง completed/failed/replayed task.

## Scope
Browser E2E, API/worker/infra orchestration, seeded local model stub/smoke option and evidence capture.

## Prerequisites / dependencies
Phase 02–17 complete.

## Exact tasks
- [ ] choose Playwright (or existing browser runner) and add deterministic local E2E configuration.
- [ ] cover login → create task → queued/running SSE → completed result.
- [ ] cover approval pause/resume, worker retry/failure display and browser reconnect `?after=` replay.
- [ ] cover authorization: user A cannot read user B task.
- [ ] keep real Ollama scenario opt-in; CI scenario uses gateway mock/stub with fixed output.

## Files/folders ที่ต้องสร้างหรือแก้
`apps/web/e2e/**`, `playwright.config.*`, `docs/e2e.md`

## Commands ที่ต้องรัน
`pnpm e2e`; `pnpm e2e:ui` (optional)

## Implementation guidance
Wait on observable API/UI condition, never arbitrary sleep. Capture trace/screenshot/video only on failure and ensure artifacts do not contain secrets. Seed fixed workflow/agent versions.

## Acceptance criteria
all four core paths pass consistently against clean local stack and failure artifacts are useful.

## Verification commands/tests
`docker compose up -d`; migrations/seeds; `pnpm e2e`; rerun selected suite.

## Common pitfalls
อย่า make CI depend on GPU/model download, อย่า use brittle text timing, อย่า skip SSE reconnection test.

## Definition of done
V1 is demonstrably usable by a browser user without manual database manipulation.

```text
Implement Phase 18 from 18-e2e.md. Add deterministic browser E2E tests for the listed complete, approval, failure/retry, replay, and authorization paths. Keep real Ollama testing opt-in and publish safe failure artifacts.
```
