# Demo Script v1.0.0

## Scenario: The AI Project Manager

1. **Login**: User logs in via Dashboard.
2. **Configuration**: Navigate to Agents and Workflows to verify pre-seeded versions.
3. **Execution**: Create a new task using a Manager Workflow.
4. **Monitoring**: Watch the event log move from queued -> unning -> completed.
5. **Intervention**: Trigger a task that requires approval and verify the dashboard pause state.
6. **Resolution**: Approve the task and observe the final result.
7. **Audit**: Check the observability logs for token usage and execution trace.
